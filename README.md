# 学习通视频与文档学习助手 V3.4.4

本项目是 [chaolucky18/xuexitongScript](https://github.com/chaolucky18/xuexitongScript) 的衍生版本，针对视频自动播放、同节多视频接续、文档自动翻页与滚动，以及小节切换稳定性进行了优化。

**感谢原作者 [chaolucky18](https://github.com/chaolucky18) 和[原项目所有贡献者](https://github.com/chaolucky18/xuexitongScript/graphs/contributors)的基础工作。** 本仓库保留上游提交历史，由 [L1Xu4n](https://github.com/L1Xu4n) 维护优化版本，不代表原作者发布或背书。

## 下载与主要功能

- [下载 3.4.4 油猴安装文件](https://github.com/L1Xu4n/xuexitongScript/releases/download/v3.4.4/v3_optimized.user.js) · [版本发布页](https://github.com/L1Xu4n/xuexitongScript/releases)
- 同一小节的多个视频按顺序播放，默认请求二倍速，支持勾选静音。
- 支持的文档约每 250 毫秒翻一页或滚动一屏，自动检查翻阅是否生效。
- 跳过平台已确认完成的小节与资源，视频结束后更快检查平台保存状态。
- 避免目录重绘和标题更新导致误暂停；面板可收起，保留停止按钮。

只需安装 **`v3_optimized.user.js`**。日常使用不需要安装 Node.js，也不用构建。

请遵守课程和平台使用规定。本脚本不伪造学习时长、不构造完成上报、不自动答题或绕过验证；播放结束也不等于平台一定已记录完成。

## 3.4.4 切换稳定性与面板收起

- 使用稳定的小节编号识别当前位置，目录元素被重新绘制后仍能认出目标，避免一直等待旧元素。
- 连续多个小节明确显示已完成时，一次进入后续第一个未完成小节；有待完成计数或状态矛盾的目录项仍保留。
- 优先用已加载课程文档的卡片编号识别步骤，不再把章节标题、提示文字的更新误判为手动切换。
- 仍检查目录与实际加载的小节是否一致，并等待旧内容被替换；真实切换不能复用旧视频或旧完成记录。
- 局部换页复用同一个课程文档时，只要实际小节/卡片编号与资源均已变化，也能确认切换；新旧可见课程框架归属冲突时仍等待，超时停止，不猜测应播放哪一个。
- 点击标题栏右侧箭头可收起/展开。收起后保留标题、状态悬停提示和“停止”，不改变播放、倍速或静音设置；刷新后恢复展开。

## 3.4.3 完成检查与快速续播

- 开始和运行中优先查看当前小节的目录完成标记。明确显示已完成、且页面没有矛盾的未完成任务点时，直接进入下一小节，不重新看已完成的视频或文档。
- 本小节只有部分资源完成时，跳过已确认完成的资源，继续剩余任务；不能用一个视频完成推断整节完成。
- 视频自然结束后，每 250 毫秒读取页面的任务点状态。确认保存后立即继续，不再固定等待 8 秒，也不再叠加一轮整页 8 秒等待。
- 没有可靠完成标记时保留一次默认 8 秒的兜底等待；这不代表平台已确认。若有明确未完成标记，则最多等待 30 秒，仍未确认会停止。
- 空计数、零计数、别的小节或嵌套资源的完成标记不会被当成当前小节完成；目录和任务点状态相矛盾时不跳过。
- 只读取页面原有完成状态，不构造保存请求、不修改任务点标记。原有二倍速和静音选项保持不变。
- 切换小节仍会核对课程框架确实换页，并保留 1.5 秒界面稳定检查；目录先变化或旧页视频迟到，都不能当成新页已就绪。这与保存确认后取消固定等待是两回事。

## 3.4.2 倍速与静音

- 视频默认请求 **2 倍速**，每个后续视频也会应用。不修改播放进度，不强行覆盖平台限制。
- 面板新增“静音播放”复选框。勾选后立即静音当前受控视频，并在后续视频开始播放前应用，避免先发声再静音；取消勾选会立即解除当前视频静音。
- 默认不强制静音；若浏览器拒绝有声自动播放，原有静音回退会同步勾选该选项。
- 静音选择仅在当前页面内保留，不写入浏览器存储；刷新后恢复默认。需要每次自动静音，可将源码设置中的 `muted` 改为 `true`。
- 停止或释放视频时恢复该视频原来的静音和倍速状态；文档滚动速度不变。

## 3.4.1 修复

- 已在实际课程页只读确认：视频 iframe 同时使用 `ans-attach-online ans-insertvideo-online`。上一版把通用附件类误认成文档，导致视频没有播放就等待任务点完成。现在视频专用类别、视频模块路径和内部真实视频优先于文档识别。
- 文档默认改为约每 250 毫秒翻一页或滚动一屏，不再每屏停留 15 秒，也不再在确认滚动成功后额外等待一个间隔。
- 到末页或底部后仍等待至少 1 秒；出现懒加载内容会继续滚动。翻页/滚动没有生效时仍停止，不假定成功。
- 文档、视频和待加载资源分别记录身份，旧文档的完成缓存不能用于视频。3.4.1 当时保留视频结束后的 8 秒等待；3.4.3 已将其优化为确认即继续、未知状态只等一次。

升级时导入本目录的新安装文件，只保留一份学习通助手启用，**刷新课程页并确认展开的面板显示 3.4.4**。仅重新点击旧面板的“开始”不会加载本地新代码。

## 本次修改

- **同小节多个视频**：按页面中的资源顺序逐个处理，当前视频结束后重新扫描本节，全部资源结束后才进入下一步骤或小节。尚未加载的播放器会等待，不直接略过。
- **文档浏览**：支持同源文档中的 PDF.js 形状分页器，以及可识别的滚动阅读区。默认约每 250 毫秒翻一页或滚动一屏，调用原生控件，不直接设置任务点完成。
- **油猴启动**：去掉 jQuery 和外部 CDN，改为原生 DOM；顶层页面单实例、等待异步加载，并在右下角显示状态、开始和停止按钮。
- **运行清理**：切换小节后等待新内容，停止后取消轮询并使过期播放回调失效。重复注入会清理旧实例。

这是正常媒体播放和文档浏览助手，不伪造学习时长、不调用完成上报接口、不自动答题、不跳过验证。

## 安装与首次验证

1. 打开 Tampermonkey 管理面板，**停用原来的学习通脚本**，避免两个版本同时控制播放器。
2. 在“实用工具”中找到“从文件导入”，选择本目录下的 `v3_optimized.user.js` 并安装。
3. 确认脚本启用，并允许 Tampermonkey 访问学习通站点。若浏览器提示“允许用户脚本”或要求开发者模式，按照扩展提示完成设置。
4. 刷新学习通的**课程播放页**，不是课程列表首页。右下角应出现“学习通助手 3.4.4”；需要静音时勾选“静音播放”。面板挡住内容时点击右侧箭头收起。
5. 先选一个含两个视频的小节，观察第一个自然结束后是否进入第二个，再测试一个文档小节。
6. 需要暂停时点助手的“停止”。查看平台目录中的完成标记，不能只看助手状态判断是否计入学习记录。

油猴元数据匹配这些路径，包含子域名和 HTTP/HTTPS：

```text
*.chaoxing.com/mycourse/studentstudy*
*.chaoxing.com/mooc2-ans/mycourse/studentstudy*
```

不匹配学校自建域名；请先确认课程播放页地址属于上述范围。

### 没有面板

- 检查油猴图标是否显示本脚本在当前页运行、是否启用，以及当前路径是否在上述范围内。
- 检查扩展的站点访问权限和浏览器用户脚本开关；安装后必须刷新已经打开的课程页。
- 不要把普通 `.js` 文件当作油猴安装文件，使用带 `==UserScript==` 元数据头的 `.user.js` 文件。

### 有面板但不播放

- 按面板提示检查验证、登录、课程加载和播放器状态。
- 浏览器拒绝有声自动播放时会尝试静音；仍不允许时，手动播放一次，再点助手“开始”。
- 视频被用户或平台暂停后，助手也停止，不拦截浏览器失焦、鼠标移出或验证事件。
- 保持目标学习页打开。浏览器后台节流、休眠和平台暂停规则仍可能影响运行。

## 控制台版本

先停用旧脚本并刷新，然后在目标播放页 F12 控制台执行 `v3_optimized.js` 的完整内容。

```javascript
app.stop();      // 停止助手，并暂停当前由助手控制的视频。
app.run();       // 重新检查当前页面并继续。
app.nextUnit();  // 手动请求下一小节；不代表当前小节已完成。
app.setMuted(true);  // 开启本页静音播放；传 false 可取消。
app.setCollapsed(true); // 收起面板；传 false 可展开，不改变播放状态。
```

油猴版运行在 DOM 沙箱中，不保证 F12 能读到 `app`。油猴版请使用页面面板；不要为了执行这些命令再粘贴一份控制台版。

## 默认设置

设置位于主脚本 `configs` 对象；修改源码后需要重新生成油猴版。也可在油猴编辑器中修改已安装脚本的同名设置。

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `playbackRate` | `2` | 默认二倍速，可设 0.5–2；平台限制仍生效 |
| `autoplay` | `true` | 当前页资源结束后自动进入下一步骤/小节 |
| `muted` | `false` | 是否主动静音，可在面板勾选；本页内沿用，刷新后恢复默认 |
| `mutedFallback` | `true` | 有声自动播放被拒绝时尝试静音 |
| `autoReadDocuments` | `true` | 允许处理支持的文档阅读器 |
| `videoCheckInterval` | `250` | 状态检查周期，单位毫秒；文档也由此轮询驱动 |
| `documentDwellMs` | `250` | 翻页/滚动操作间隔，最小 100 毫秒，实际也受检查周期影响 |
| `documentBottomDwellMs` | `1000` | 文档末页/稳定底部的独立等待时间，至少 1 秒 |
| `documentMaxMs` | `1800000` | 单文档最多 30 分钟，防止无限滚动 |
| `settleMs` | `8000` | 没有可靠保存标记时的兜底等待；已确认则不等待，视频与整页不重复等待 |
| `startupTimeoutMs` | `60000` | 最长等待课程目录 60 秒 |
| `resourceTimeoutMs` | `30000` | 资源加载、翻页、切换和平台确认最多等待 30 秒 |

初次测试建议保留默认值。文档每页停留时间只是浏览节奏，不是平台认定完成的阈值。

## 文档适配范围

- 候选文档：排除视频后的 `.ans-attach-online` 框架、已知文档模块路径、可识别 PDF.js 容器。视频专用类别、模块路径和内部可见视频具有更高优先级。
- 分页：`#pageNumber`、`#numPages` 和下一页按钮；每次点击后都核对页码。
- 滚动：同源页面的滚动根节点或具有可测量高度的阅读器；每次滚动后核对位置，底部高度变化时继续浏览。
- **不支持自动处理**：跨域文档、浏览器内置 PDF、未知 Canvas/PPT 阅读器、无可靠页码或滚动区域的课件。会显示提示并停止，不直接跳过。
- 如果页面存在可识别的任务点图标，会等待平台完成标记；超时就停下。没有这些标记时只能确认本地媒体/浏览结束，不能证明平台已记录。

这批选择器和行为已做合成 DOM 测试，但当前真实课程的文档 DOM 尚未取得。因此不能保证所有课程文档通用。

## 初学者需要理解的 3 个知识点

1. **DOM 和 iframe**：一个小节可以包含多个嵌套播放器，找到第一个不等于找到全部；跨域框架不能直接读取。
2. **异步与状态机**：点击、加载、播放、结束和保存不是同时发生的，必须逐步观察结果，不能只等固定秒数就假定完成。
3. **油猴入口与权限**：`.user.js` 头部决定运行网站和时机；浏览器允许扩展运行、脚本已启动、平台已记录进度是三件不同的事。
